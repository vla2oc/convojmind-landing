- 2026-09-20 — Переключатель языка — пара `PL | EN` в фиксированном порядке (`Header.tsx`, `LANGS`): текущий код белый и не ссылка (`aria-current`), другой — `--text-muted`, при наведении `--primary`, при нажатии `scale 0.98` пружиной (`PressLink`); между ними тонкая черта; `<nav aria-label>` подписан на языке страницы (`languageAria` в словаре) — решение владельца: без стрелки, «чтобы пользователь понимал, что это смена языка». Замер CDP `[проверено]`: ссылка `#a3a3a3` → hover `#9EF01A`, зажато 0.98, клик → `/en`, `lang=en`; overflow 0 на 360 и 1280 на обеих страницах.

Переход между группами — полная перезагрузка (Caveats route-groups), для смены языка это нормально. `_not-found` собрался статическим и без верхнего `app/layout.tsx` `[проверено]`; `/nie-ma` → 404.
